## Цель

Привести экраны Home (`view='mode0'`) и Ready-to-scan (`view='scanner' && status='idle'`) к визуалу макетов `01-home.png` / `02-ready-to-scan.png`: подключить `<Header>` к новому API (`icon='gear'` на Home, `icon='home'` на Ready-to-scan), реализовать `handleNavigateHome` без сброса state, обновить визуал чипов `ScopeSelector` (на 4 значениях).

## Зачем

Третья фаза редизайна v1.x по принципу «токены → компоненты → экраны». Без подключения нового Header API (введён в Ф.16.2) UX-навигация остаётся на deprecated `onSettingsClick` — это противоречит решению PO от 2026-05-08 о контекстной модели иконки (gear только на Home, home на остальных продуктовых экранах). `handleNavigateHome` — новый путь навигации без сброса `detection`/`scopeChoice`/`explanationsRef`, отличающийся от `handleReset`; реализуется именно сейчас, потому что первый потребитель — Ready-to-scan. ScopeSelector — единственный экран, где визуальный язык чипов виден сразу при запуске плагина после `Got it`, поэтому стилевая сверка с `02` приоритетна для submission v1.x.
