## Цель

Привести карточку одного нарушения (`ReportView.tsx`, бывший `ReviewFix.tsx`) в соответствие с эталонами 04/05: подключить `BackButton`, мигрировать Header на `icon='home'` API, переработать композицию карточки (dashed-preview, inline pagination справа от H3 «Цвета», склейка hint в один параграф), удалить мёртвый проп `onFixApplied` и неиспользуемую функцию `severityColor`. Параллельно `@backend` обновляет два секционных комментария в `src/shared/strings.ts`. Параллельно `@ui-engineer` удаляет deprecated `onSettingsClick` из Header после миграции последних потребителей.

## Зачем

Карточка нарушения — самый сложный экран плагина и единственный, по которому пользователь принимает решения «исправить / пропустить / скрыть». Текущий визуал расходится с эталонами 04/05 по 9 элементам (Header API, BackButton a11y, layout pagination, H3-категория, dashed preview, склейка hint, severity-точка, container padding) — это формирует разрыв между макетом 2026-05-07 и UI плагина, блокирующий v1.0-submission. Параллельно закрываем накопленный долг: мёртвый проп `onFixApplied` (известное ограничение #1 из session-report-01, после `ec830d3` глобальный обработчик в `App.tsx:115-117` сам вызывает `handleFixApplied`) и неиспользуемая `severityColor` после удаления severity-dot из карточки. Удаление deprecated `onSettingsClick` из Header — закрытие долга, который комментарий в Header.tsx отнёс на Ф.16.3, но Ф.16.3/Ф.16.4 не закрыли.
