description: QA-прогон последнего шага — acceptance criteria + регрессия + интерпретация скриншотов
---

Запрос пользователя: $ARGUMENTS (если пусто — последний шаг сессии)

Делегируй `@qa`:

1. Прочитать acceptance criteria шага.
2. Сформулировать тест-матрицу для прогона в Figma desktop.
3. Если найден баг — оформить через skill `bug-report`.
4. Регрессия: выборка из последних 2 фаз (Cmd+Z после Fix, Spinner на сканировании, кэш Preview, симметрия PluginMessage в новых обработчиках).
5. Сверка с runtime-логами `logs/runtime.log` если есть.

Человек запускает плагин в Figma desktop сам — `@qa` интерпретирует скриншоты и логи, не делает прогон в браузере.

Финальный вывод — QA-отчёт по формату из роли `@qa`. Если всё чисто — явный «✅ acceptance criteria выполнены, можно коммитить».
