Запрос пользователя: $ARGUMENTS

Это комплексный шаг. Выполни «Порядок при комплексных шагах» из CLAUDE.md:

1. **Разведка и выбор варианта** — `@lead-architect` строит impact map по skill `impact-map`. Если развилка A/B — выбирает сам по фильтрам приоритетов **или** эскалирует к Product Owner (по правилам раздела «Когда выбираешь сам, когда эскалируешь пользователю» в SKILL.md). Затем формулирует шаг через skill `step-format`.
2. **Исполнение** — делегируй исполнителю по правилам маршрутизации из CLAUDE.md:
   - `@backend` — `src/sandbox/*` и `src/shared/types.ts`.
   - `@ui-engineer` — всё `src/ui/*` (экраны, `components/*`, `components/ui/*`, `tokens.ts`, `aiClient.ts`, шрифты).
3. **QA** — `@qa` прогоняет acceptance criteria по шагу + регрессия из последних 2 фаз. Использует skill `bug-report` если найден баг.
4. **Коммит и документация** — `@release-scribe` делает атомарный коммит после явного «✅» от Product Owner. Версия в трёх местах одновременно (`package.json`, `manifest.json`, `aboutVersion` в `src/shared/strings.ts`). Если в шаге появились новые термины — обновляет глоссарий. Отчёт сессии — только при `/close-session`, не на каждом шаге.

После каждого этапа — короткий статус для человека (1 строка: что сделано, кто следующий).

Если на любом этапе нужен явный «✅» от Product Owner (push, публикация, изменение `manifest.json`, мутация Figma-документа) — останавливайся и спрашивай через `ask_user_input_v0`.
