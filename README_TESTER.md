# DesignLint AI — инструкция для тестера

Плагин для Figma, который проверяет макет на соответствие дизайн-системе.

## Установка (5 минут)

1. Распакуй архив `designlint-ai.zip` в любую удобную папку
2. Открой Figma Desktop (не веб — плагины разработки работают только в десктоп-версии)
3. В меню: **Plugins → Development → Import plugin from manifest…**
4. Выбери файл `manifest.json` из распакованной папки
5. Плагин появится в меню: **Plugins → Development → DesignLint AI**

## Получить AI-ключ (опционально, 2 минуты)

Плагин работает без AI-ключа, но с ним ты получишь объяснения рекомендаций.

1. Зайди на https://aistudio.google.com/apikey
2. Нажми **Create API Key**
3. Скопируй ключ (начинается с `AIza...`)
4. В плагине: **⚙ (шестерёнка) → поле Google API Key → Сохранить ключ**

## Что тестировать

- Открой файл с дизайн-системой (цвета/шрифты в виде Styles или Variables)
- Выдели Section, Frame или элементы
- Запусти плагин: **Plugins → Development → DesignLint AI**
- Выбери источники ДС и область проверки → **Запустить аудит**
- На экране «Dashboard» посмотри список нарушений
- Нажми **«Исправить по очереди»** и попробуй применить рекомендации
- В конце на экране «Готово» — нажми **«Убрать маркеры»**, чтобы убрать служебные точки с холста
